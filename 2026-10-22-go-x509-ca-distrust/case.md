# Go 中间 CA 信任拦截：漏洞分析与安全自查

> [Go 官方问题 #82345](https://go.dev/issue/82345) 将此事标为 **CVE-2026-111943**，要求紧急升级。Go 1.27.3 和 1.26.10 在 `crypto/x509` 验证时过滤包含特定中间证书的证书链，以应对相关 CA 运作的安全疑虑。**升级开发机工具链后，已部署的旧 Go 二进制仍须重新构建并重新部署。**

## 已确认事实与截图口径

| 项目 | 官方可确认内容 | 边界 |
|---|---|---|
| 事件 | 特定 CA 的部分中间证书不再被 Go 信任，`Certificate.Verify` 返回的链会过滤这些中间证书 | 官方表述为相关 CA 的“特定安全疑虑”，未在问题单中证实私钥已泄露、已签发何种恶意证书或已造成在野攻击 |
| 标识与优先级 | CVE-2026-111943；问题单标记 URGENT track，并明确建议立即升级 | URGENT 是项目的处理优先级，不等于已有 CVSS 或确认所有应用均可直接被远程利用 |
| 修复 | [Go 发布历史](https://go.dev/doc/devel/release)：**go1.27.3、go1.26.10 均于 2026-10-19 发布**，说明含 `crypto/x509` 安全修复 | Go 1.25 及更早分支没有在这次发行说明中提供对应新版本；自定义构建/供应商回补另核实 |
| 拦截机制 | [1.27 回补提交](https://github.com/golang/go/commit/90617fb7ceb59cf08bee7826bb51b8c8fb8c11de)按中间证书的 **SHA-256 SPKI 哈希**识别并过滤链，补丁数据中可见 **8 条哈希**；同时触及通用验证以及 Darwin/Windows 系统验证分支 | 8 条哈希不等于官方公开确认“8 个私钥泄露”或“8 个根证书撤销”。这是 Go 验证策略修正，不能据此宣称系统信任库也被自动更新 |

## 影响分析

风险出现在使用 Go `crypto/x509` 证书链验证并可能遇到这些中间证书的流程：向外发起 TLS 连接验证对端证书、以 mTLS 校验客户端证书、验签或其他调用 `Certificate.Verify` 的业务。实际是否经过受影响中间证书取决于信任锚、链构建、业务信任策略与连接对象；**一个二进制的构建版本落在修复前并不证明它已经接受恶意证书**。

若某条证书链本来只因这批中间 CA 而被旧程序接受，新版会过滤该链；如有其他不含被拦截中间证书的有效链仍可能被接受。正常服务也可能因依赖该 CA 而出现证书验证失败，升级前应梳理依赖并通知业务负责人。不能为“快速恢复”而关闭 TLS 验证、随意设 `InsecureSkipVerify` 或把相关证书加入自定义可信根。

此变更在 Go 标准库里；修改 `go.mod` 中的依赖版本或只更新系统 CA 证书包不保证修复一个**用旧 Go 构建并运行的二进制**。同一主机可以同时有多个 Go 程序和多套工具链，部署镜像的基础层版本也不能替代应用二进制构建信息。动态链接、厂商打包和非标准验证代码需分别核验。

## 安全自查与处置

1. **盘点构建产物。** 登记服务、负责人、节点/容器、实际运行可执行文件路径与哈希、镜像摘要、构建 Go 版本和构建时间；供应商产品、旁路守护进程及静态部署文件同样纳入。用可信 Go 工具的 `go version -m /path/to/binary` 只读解析构建信息，不执行目标程序；读取失败标为待核实。`go.mod` 中的 `go` 指令只约束模块/工具链语义，不是产物版本证据。
2. **区分业务用途。** 确认程序是否执行标准库证书链校验：出站 HTTPS/TLS、mTLS 客户端证书、签名验证、内部 PKI、证书管理和供应商接口。收集业务证书链与验证失败告警，重点核查是否依赖被拦截中间 CA；不要主动向未授权端点探测。
3. **按分支升级并重建。** 用 Go **1.26.10 / 1.27.3** 或后续包含修复的受支持版本重新构建，部署新镜像/二进制，重启工作负载并核对所有副本的运行文件。供应商产物应索取修复声明、包版本及构建证明。保留回滚和证书兼容性验证，但不要回滚到不受控的旧信任状态。
4. **查历史异常。** 将既有 TLS 握手、证书验证、CA 变更、反向代理和客户端连接日志与异常证书链关联。缺少链细节的日志或没有报错不能证明历史上未受影响；必要时在可信环境按业务采集证书链进行人工复核。若已有可疑证据，执行内部证书/密钥处置流程。

离线版本台账检查器、证据格式与解释见 [skill/SKILL.md](skill/SKILL.md)。脚本仅比较清单中的 Go **构建版本字段**，不会连接 TLS 服务、读取或验证业务证书。
