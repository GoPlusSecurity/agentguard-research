# 离线自查工具验证与边界

从 `skill/` 目录运行：

```bash
python3 -B -m unittest discover -s scripts -p 'test_*.py' -v
```

测试覆盖：四个上游维护分支修复门槛的前一版/修复版/后一版、老版本和未知构建的保守处理、对公网优先级、无效/缺失证据、Windows/POSIX 进程路径归一化、非匹配子进程、缺失事件及 CSV 表头错误。脚本仅解析用户提供的本地 CSV；不执行资产二进制、不连接网络、不向 PHP 服务发送请求。检查通过只证明该工具在合成证据上的既定行为，不证明真实资产安全。

局限：版本比较仅支持四个上游稳定分支的纯三段式号码，无法核验包签名、供应商回补、源码修复提交、实际 worker 已切换或自定义构建；没有专属 IOC。资产清单可能漏掉供应商内置运行时和服务端其他节点；进程事件是否留存取决于采集与保留策略。规则命中只是通用调查线索，未命中只说明给定事件范围内无匹配。
